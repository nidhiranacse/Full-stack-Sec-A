🔗 How Inheritance Works Here

Every page uses {% templatetag openblock %} extends "myapp/base.html" {% templatetag closeblock %} at the top.

The master base.html defines three key blocks:

  • {% templatetag openblock %} block title {% templatetag closeblock %} — page-specific browser tab title
  • {% templatetag openblock %} block notification {% templatetag closeblock %} — persistent alert box (Task 8.2)
  • {% templatetag openblock %} block content {% templatetag closeblock %} — main page body
{% endblock %}
