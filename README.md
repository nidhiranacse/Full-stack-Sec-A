# Student Records REST API (Node.js + Express)

## Run
1. Install Node.js (v18+)
2. In this folder run:  npm install
3. Start server:       npm start
4. API at http://localhost:3000

## Endpoints
- POST   /students        {name, email, age}
- GET    /students        (optional ?minAge=N)
- GET    /students/:id
- DELETE /students/:id
