\# LAB SHEET 05: FORM VALIDATION ARCHITECTURE \& CONTROLLED INPUTS IN REACT



\## Aim



To create a functional and responsive form validation module using controlled components and React state management.



\## Primary Syllabus Exercise



Create a functional, responsive Login Form module using controlled component inputs inside the React JS library architecture.



\## Tasks



\### Task 5.1: Dynamic Regex Validation



Implement dynamic regular expression based validation in the login form. The form should check user input and display interactive error messages when the entered values do not satisfy the required security patterns.



\### Task 5.2: Password Strength Checker



Create a password strength checker component that evaluates the entered password and displays its strength using a dynamic visual progress bar.



\### Task 5.3: Multi-Step User Onboarding Form



Create a multi-step onboarding form wizard using child components. The form should maintain the entered data while moving between steps and submit the complete information at the end.



\## Technologies Used



\- React JS

\- JavaScript

\- HTML5

\- CSS3

\- React Hooks

\- Regular Expressions

\- Controlled Components



\## Expected Learning Outcomes



1\. Understand controlled components in React.

2\. Perform form validation using regular expressions.

3\. Manage form data using React state.

4\. Create reusable child components.

5\. Implement dynamic UI feedback.

6\. Build a multi-step form using React.
