📘 About This Project

This Django application demonstrates a modular web architecture where common interface elements are maintained in a reusable master template.

🧠 Architecture

🏗️ Master Template base.html contains the common navigation, layout, notification area and footer.
🔗 Child Templates Home, About and Contact pages inherit the master layout using Django template inheritance.
⚙️ Dynamic Context Each view sends an active-page identifier to highlight the current navigation item.
🛡️ Server Processing Contact feedback is validated on the server before being written to the development log.

🎯 Lab Objective

The objective is to build a reusable and maintainable Django UI using template inheritance, dynamic navigation and server-side feedback processing.
