# Full Stack Development Lab — Set A (Even Roll Numbers)

This ZIP contains both Set A practicals from the supplied lab manual.

## A1 — Student Records REST API
1. Open a terminal in `A1_StudentRecordsAPI`.
2. Run `npm install`.
3. Run `npm start`.
4. API URL: `http://localhost:3000`.

Endpoints: POST `/students`, GET `/students`, GET `/students?minAge=18`, GET `/students/:id`, DELETE `/students/:id`.

## A2 — Feedback Form with Validation
1. Open a terminal in `A2_FeedbackFormApp`.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the URL printed by Vite (usually `http://localhost:5173`).

The form is exported from `src/FeedbackForm.jsx` and includes the required `data-testid` values.
