Practical A1 Specifications 20 Marks

Built with Node.js and Express. Stores records in memory with auto-increment ID generation starting at 1. IDs of deleted records are never reused.

Method Endpoint Status Description
POST /students 201 Creates student: { name, email, age }. Returns 400 on invalid input, 409 on duplicate email.
GET /students 200 Lists all students in insertion order. Optional ?minAge=<n> filters age >= minAge.
GET /students/:id 200 / 404 Returns student by ID or 404 { "error": "Student not found" }.
DELETE /students/:id 204 / 404 Deletes student with empty body or 404 { "error": "Student not found" }.
