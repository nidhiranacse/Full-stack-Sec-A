About Us

The Student Portal is a web-based application developed to demonstrate the use of Flask, template inheritance, and modular user interface development.

Our Mission

Our mission is to create a simple, efficient, and accessible platform that makes it easier for students to interact with the application and access useful information.

Technology Used

  • Python – Application programming
  • Flask – Web application framework
  • HTML – Web page structure
  • CSS – Styling and layout
  • Jinja2 – Template inheritance and dynamic content

Template Inheritance

The application uses a master template called base.html. Common elements such as the header, navigation menu, notification area, and footer are defined in the master template. Individual pages inherit this structure and provide their own content.

This approach makes the application easier to maintain, reduces repetition, and provides a consistent user interface across all pages.
