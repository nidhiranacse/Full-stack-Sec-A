Customer Behaviour Prediction using Web Usage Mining

Analyzed 12,330 e-commerce user sessions across 18 behavioral features — bounce rate, exit rate, page value — to predict purchase intent. Trained and compared four classifiers; preprocessed with label encoding, feature scaling, and session-level aggregation. Deployed as an end-to-end Flask app with an HTML/CSS/JS frontend for real-time prediction.
