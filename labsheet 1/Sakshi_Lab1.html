HTML5
Category: Markup Language
Description: HTML5 is the standard markup language used to structure content on web pages. It provides semantic elements such as header, nav, main, section, article, and footer.

Category: Styling Language
Description: CSS is used to control the presentation and layout of HTML documents, including spacing, typography, positioning, and responsive page design.
JavaScript
Category: Programming Language
Description: JavaScript is a programming language used to add interactivity and dynamic behavior to web pages. It can manipulate HTML elements and respond to user actions.
Python
Category: Programming Language
Description: Python is a high-level programming language known for its simple syntax and wide use in web development, automation, data analysis, and artificial intelligence.
React
Category: JavaScript Library
Description: React is a JavaScript library used to build interactive and reusable user interfaces, particularly for modern single-page web applications.
Node.js
Category: JavaScript Runtime
Description: Node.js allows JavaScript to run outside the browser. It is commonly used for developing server-side applications and backend services.
GitHub
